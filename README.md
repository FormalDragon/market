# Market Regime Dashboard

Streamlit 기반 투자 데이터 분석 대시보드 프로젝트입니다.

본 프로젝트는 Skills.md에 정의된 분석 규칙을 기준으로 내장 글로벌 자산 데이터와 사용자 업로드 데이터를 분석합니다.

## 주요 기능

- 내장 글로벌 자산 데이터 기반 시장 상태 진단
- 5일·20일 수익률 계산
- Risk-on / Risk-off / Rate Pressure / Dollar Stress / Volatility Expansion / Mixed 분류
- 사용자 CSV 업로드
- 컬럼 매핑 및 데이터 검증
- 글로벌 시장 상태와 특정 시장 반응 비교
- Streamlit 기반 대시보드 제공
